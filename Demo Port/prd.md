# PRD: 개발자 프로필 웹사이트 (Demo Port)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | Demo Port |
| 목적 | 개발자 개인의 기술 스택, 프로젝트, 연락처를 한 곳에서 소개하는 프로필(포트폴리오) 웹사이트 |
| 대상 사용자 | 채용 담당자, 협업 제안자, 동료 개발자 |
| 연락처 | great@gmail.com |
| 주 개발분야 | Python, HTML5 |

## 2. 목표

- 방문자가 30초 안에 "누구이며, 무엇을 잘하는지"를 파악할 수 있게 한다.
- Python, HTML5 기반의 대표 프로젝트를 보여준다.
- 이메일로 바로 연락할 수 있는 경로를 제공한다.
- 데스크톱과 모바일 모두에서 잘 보이게 한다.

### 비목표 (이번 범위 아님)

- 회원가입/로그인, 관리자 페이지
- 블로그 CMS, 댓글 기능
- 다국어 지원 (추후 검토)

## 3. 페이지 구성 (단일 페이지, 섹션 스크롤)

### 3.1 헤더 / 내비게이션
- 이름(또는 로고) + 섹션 이동 메뉴: About, Skills, Projects, Contact
- 스크롤 시 상단 고정, 모바일에서는 햄버거 메뉴

### 3.2 Hero (메인 소개)
- 이름, 한 줄 소개 (예: "Python과 HTML5로 웹을 만드는 개발자")
- CTA 버튼: "프로젝트 보기", "연락하기"

### 3.3 About (자기소개)
- 짧은 소개글 (3~5문장)
- 프로필 이미지 (선택)

### 3.4 Skills (기술 스택)
- **주력**: Python, HTML5
- **보조**: CSS3, JavaScript, Git 등 (추후 확정)
- 카드 또는 배지 형태로 표시

### 3.5 Projects (프로젝트)
- 프로젝트 카드 3~6개
- 카드 항목: 제목, 설명, 사용 기술 태그, GitHub/데모 링크, 썸네일(선택)
- 프로젝트 데이터는 별도 파일(예: `projects.json`)로 관리해 수정이 쉽도록 함

### 3.6 Contact (연락처)
- 이메일: `great@gmail.com` (`mailto:` 링크)
- GitHub, LinkedIn 등 외부 링크 (추후 확정)

### 3.7 Footer
- 저작권 표기, 마지막 업데이트 연도

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| F-01 | 메뉴 클릭 시 해당 섹션으로 부드럽게 스크롤 | 높음 |
| F-02 | 반응형 레이아웃 (모바일 360px ~ 데스크톱 1440px) | 높음 |
| F-03 | 이메일 링크 클릭 시 메일 클라이언트 실행 | 높음 |
| F-04 | 프로젝트 목록을 데이터 파일에서 읽어 렌더링 | 중간 |
| F-05 | 라이트/다크 모드 (시스템 설정 따름) | 중간 |
| F-06 | 이메일 주소 복사 버튼 | 낮음 |

## 5. 비기능 요구사항

- **성능**: Lighthouse Performance 90점 이상, 첫 화면 로딩 2초 이내
- **접근성**: 시맨틱 HTML5 태그(`header`, `nav`, `main`, `section`, `footer`) 사용, 이미지 `alt` 제공, 키보드 이동 가능
- **SEO**: `title`, `meta description`, Open Graph 태그 설정
- **호환성**: 최신 Chrome, Edge, Safari, Firefox

## 6. 기술 스택

| 구분 | 선택 |
|---|---|
| 마크업 | HTML5 |
| 스타일 | CSS3 (Flexbox/Grid), 외부 프레임워크 없이 시작 |
| 스크립트 | 바닐라 JavaScript (최소한) |
| 로컬 개발 서버 | Python (`python -m http.server`) |
| 배포 | GitHub Pages 또는 Netlify (정적 호스팅) |

> 선택 확장: 추후 Python(Flask/FastAPI)으로 연락 폼 백엔드나 프로젝트 API를 붙일 수 있음.

| 단계 | 내용 |

- 표시할 이름(실명/닉네임)과 한 줄 소개 문구
- 소개할 프로젝트 목록과 링크
- GitHub, LinkedIn 등 추가 링크 여부
- 선호하는 디자인 톤 (미니멀, 컬러풀 등)
